MDC 비동기 컨텍스트 전파

HTTP 요청이 들어오면 RequestIdFilter가 UUID를 MDC에 삽입합니다. MdcTaskDecorator가 FCM Executor에 적용되어 비동기 콜백 스레드로 MDC 스냅샷을 복사합니다. 덕분에 모든 로그에 requestId가 포함되어 Loki에서 단일 요청 흐름을 추적할 수 있습니다.

RequestIdFilter 역할

모든 HTTP 요청에 대해 X-Request-ID 헤더를 읽거나, 없으면 UUID를 생성해 MDC에 삽입합니다. 응답 헤더로도 반환하므로 클라이언트에서 요청 추적이 가능합니다.

MdcTaskDecorator 역할

Spring의 TaskDecorator를 구현해 FCM 콜백 Executor의 두 스레드풀 (fcmCallbackExecutor, fcmDefaultExecutor)에 적용됩니다. 부모 스레드의 MDC 스냅샷을 자식 스레드에 복사하고 실행 후 반드시 MDC.clear()합니다.

Loki에서 추적 쿼리

Loki LogQL로 단일 요청 전체 로그를 조회할 수 있습니다.
{application="ajouevent-be-v2"} |= "requestId=abc-123"
HTTP 스레드 → FCM 콜백 스레드까지 같은 requestId로 연결됩니다.

데이터 파이프라인

메트릭과 로그는 각각 독립된 파이프라인으로 Grafana에 수렴됩니다. Prometheus는 Pull 방식으로 스크랩하고, Loki는 앱이 Push하는 구조입니다.

Pull 방식 — Prometheus

Prometheus가 15초마다 /actuator/prometheus에서 데이터를 가져갑니다. 앱이 다운되면 스크랩이 실패해 자동으로 공백 구간이 생기며, up 메트릭으로 장애를 감지할 수 있습니다. 보존 기간은 15일로 설정했습니다.

Push 방식 — Loki4j

Loki4j의 비동기 배치 Appender가 로그를 모아서 일괄 전송합니다. 512건 또는 3초마다 한 번씩 POST /loki/api/v1/push를 호출합니다. ch.qos.logback.classic.AsyncAppender로 한 번 더 감싸 앱 응답 지연을 최소화합니다.

cAdvisor — Docker 메트릭

cAdvisor가 Docker 소켓과 cgroup을 직접 읽어 각 컨테이너의 CPU, 메모리, 네트워크 I/O를 수집합니다. 운영 환경에서는 컨테이너별 id와 네트워크 인터페이스 메트릭을 조합해 대시보드에 표시합니다.

컴포넌트 상세

각 서비스의 역할과 포트 정보입니다.

🚀

Spring Boot App

:8080 API · :9090 Actuator

메인 애플리케이션. 9090 포트는 AWS 보안그룹에서 모니터링 IP로만 제한됩니다. /actuator/prometheus에서 Micrometer 메트릭을 노출합니다.

📊

Prometheus

Host :9091 → Container :9090

Pull 방식 시계열 메트릭 DB. PromQL 쿼리 언어로 집계·분석. Grafana의 기본 데이터소스. --storage.tsdb.retention.time=15d로 15일 보존.

📋

Loki

:3100

Prometheus와 동일한 레이블 모델을 사용하는 로그 집계 시스템. 로그 내용은 인덱싱하지 않아 ELK 대비 스토리지 비용이 낮습니다. LogQL로 로그 필터링·집계.

📈

Grafana

:3000

Prometheus(PromQL)와 Loki(LogQL)를 동시에 조회하는 통합 대시보드. 대시보드·데이터소스는 monitoring/grafana/provisioning으로 코드화하여 자동 프로비저닝됩니다.

🔍

cAdvisor

Host :8181 → Container :8080

Docker 컨테이너의 CPU · 메모리 · 네트워크 · 블록 I/O를 실시간 수집. privileged 권한과 Docker 소켓 마운트가 필요합니다. Prometheus가 15초마다 스크랩.

🔴

Redis 7

:6379

조회수 더티셋 패턴, 캐시, FCM 토큰 관리에 사용. AOF 영속성 활성화. Spring Actuator Redis 메트릭이 Prometheus로 노출됩니다.
