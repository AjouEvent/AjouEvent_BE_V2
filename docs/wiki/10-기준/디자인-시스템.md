## 확인된 불일치

- Design language is explicitly 'Toss Design System' (comments in tailwind.config.js and index.css). Brand primary = #3182F6 (Toss blue), not Ajou navy; Ajou navy #003876 is a secondary accent used 3x. 근거: `design-tokens.json` notes 1.
- Almost all colors are hard-coded arbitrary Tailwind values (bg-[#3182F6] etc.). The named Tailwind tokens toss.*, ajou.navy, ajou.50/100 are defined but never used as classes; only bg-surface is used once. 근거: `design-tokens.json` notes 2.
- shadcn HSL CSS variables don't match their own hex comments: --background hsl(220 14% 96%) = #F3F4F6 (comment says #F9FAFB), --primary = #2E87F5 (vs #3182F6), --destructive = #F64150 (vs #F04452), --foreground = #0F1729 (vs #191F28). Dialog content uses bg-background, so modals render light gray #F3F4F6, not white. 근거: `design-tokens.json` notes 3.
- Radius override: tailwind borderRadius.lg = var(--radius) = 12px, md = 10px, sm = 8px. So rounded-lg and rounded-xl both render 12px; Tailwind defaults (8/6/2px) don't apply. 근거: `design-tokens.json` notes 4.
- Gray inconsistency: 6 near-white grays for backgrounds/borders: #F9FAFB, #FAFBFC, #F8F9FA, #F5F6F8, #F5F5F5, #F2F4F6, #F0F2F5 (plus HSL #F3F4F6). Border uses 4 different grays (#E5E8EB, #F0F2F5, #F5F6F8, #F2F4F6). 근거: `design-tokens.json` notes 5.
- Pink/red tints: #FFF0F1, #FFF0F0, #FFE8EA, #FFE0E3 are near-duplicates; error text uses both #F04452 and Tailwind red-500 (#EF4444). Like color is #FF4D6D in EventCard but #FF5B5B in FilledBookmarkIcon.svg. 근거: `design-tokens.json` notes 6.
- Primary hover/press duplicates: #1B6EE8 vs #2070E8 (hover) and #1760D1 vs #1560D4 (pressed). 근거: `design-tokens.json` notes 7.
- Active nav icon SVGs are filled #2366AF (old blue) while the active label is #3182F6; inactive icons #B8BFC6 at 35% opacity. 근거: `design-tokens.json` notes 8.
- Arbitrary text sizes (10/11/14/17/20px) have no explicit line-height and inherit 1.5 from Tailwind preflight. Body letter-spacing -0.02em everywhere; titles use tracking-tight (-0.025em). 근거: `design-tokens.json` notes 10.
- Dialog/Select use data-[state=open]:animate-in / zoom-in classes but tailwindcss-animate plugin is not installed (plugins: []), so those enter/exit animations are no-ops. SubscribeStatusDropdown references animate-[ring_1s...] with no 'ring' keyframe defined. 근거: `design-tokens.json` notes 11.
- Toaster passes '--normal-bg': 'var(--popover)' which resolves to a bare HSL triplet ('0 0% 100%'), not a valid color; sonner richColors defaults effectively apply. 근거: `design-tokens.json` notes 12.
- Unused/dead UI: components/ui/dropdown-menu.jsx (never imported), components/NavButton.jsx (unused; references non-existent Nav*On/Off.svg), DailyModal (showModal never true), PasswordConfirmationPage (no route). 근거: `design-tokens.json` notes 13.
- No app max-width container; layout is full-bleed with md:(768px) two-column split on Home and EventDetail. For Figma use a 375/390 mobile frame with 20px side padding. 근거: `design-tokens.json` notes 14.
- Not present in code: toggle/switch, bottom sheet, D-day badge, pagination control, dark mode. 근거: `design-tokens.json` notes 15.
